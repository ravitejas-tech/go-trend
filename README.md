# GoTrend

GoTrend is an AI-powered image generation platform where users can transform their photos using trending image generation styles and templates.

Instead of writing complex AI prompts, users can simply select a template, upload their image, and generate a new image based on the selected trend.

## Product Vision

Make trending AI image generation simple and accessible to everyone.

Users should be able to discover popular image trends and create their own versions with minimal effort.

---

# Core Features

## User Features

### Browse Templates

Users can explore available image generation templates organized by categories.

Examples:

* 90s Nostalgia
* Professional Portfolio
* Cinematic Portraits
* Vintage Photography
* Anime Styles
* Social Media Trends
* Fashion & Lifestyle

### Select a Template

Users can view a template preview, title, and description before generating an image.

### Upload Image

Users can upload their own image to use as the source for AI image generation.

### Generate Image

The selected image and template are used to generate a new AI-powered image.

### Download Image

Users can preview and download their generated images.

### Generation History

Users can view their previously generated images.

---

# Admin Panel

The admin panel allows the platform owner to manage image generation trends and templates.

## Template Management

Admins should be able to:

* Create new templates
* Edit existing templates
* Delete templates
* Publish or unpublish templates
* Mark templates as trending
* Assign categories
* Upload template preview images
* Add and edit AI prompts

## Admin Dashboard

Basic dashboard metrics:

* Total users
* Total image generations
* Popular templates
* Failed generations
* Recent activity

# Basic User Flow

```text
User visits GoTrend
        ↓
Browses trending templates
        ↓
Selects a template
        ↓
Uploads a photo
        ↓
AI generates the image
        ↓
User previews the result
        ↓
Downloads the generated image
```

---

# Basic Admin Flow

```text
Admin logs into dashboard
        ↓
Creates a new template
        ↓
Adds template details and AI prompt
        ↓
Uploads preview image
        ↓
Publishes template
        ↓
Template becomes available to users
```
